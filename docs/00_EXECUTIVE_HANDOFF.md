# Executive Handoff

## Canonical architecture decision

Zero-Mass Element and Global Variables remain separate scientific programs. Shared epistemic infrastructure is extracted into a third package:

```text
Global Variables ----\
                      >---- Physics Evidence Core v0.1
Zero-Mass Element ---/
```

PEC contains generic evidence, provenance, certification, no-leakage comparison, and intervention-selection machinery. It MUST NOT contain the Global Variables central physical conjecture, and Zero-Mass Element MUST NOT use that conjecture as a prior.

## Zero-Mass Element v0.2 mission

The immediate mission is ZME-B001: make reproducible nuclear-mass predictions using only information available at a historical cutoff, freeze the predictions, then score them against data that became eligible later.

The first production benchmark is not Z=154-156. Unknown-nucleus mode remains locked.

## Why this release exists

v0.1 defined the scientific architecture. v0.2 turns the strongest ideas in the supplied Global Variables repository into reusable software contracts and binds them to a concrete historical-prediction experiment.

## Release products

- `physics-evidence-core` v0.1: shared evidence/provenance/certificate kernel.
- `zero-mass-element` v0.2: nuclear-specific data/model/benchmark application.
- `ZME-B001`: historical nuclear mass prediction benchmark.
- Global Variables migration patch and compatibility plan.
- Agent task graph and acceptance gates.

## Scientific firewall

PEC may carry facts such as:

```text
"this value came from AME2003"
"this model used these training nuclides"
"this prediction interval was 90 percent"
"this target was not present in the training snapshot"
```

PEC must not carry a domain conclusion such as:

```text
"fundamental constants are generated by operator R"
```

unless that statement is represented as an explicitly domain-owned hypothesis supplied by Global Variables itself.

## Definition of v0.2 success

v0.2 is complete only when all of the following are true:

1. Global Variables still passes its existing certified runner.
2. Global Variables also supports ordinary `python -m pytest` through a non-invasive bridge.
3. PEC is installable as an independent Python package and its tests pass.
4. Zero-Mass Element is installable separately and imports PEC as a dependency.
5. ZME-B001 runs end-to-end on a synthetic fixture.
6. ZME-B001 runs on official historical AME snapshots after normalization by the coding agent.
7. Every prediction has a content-addressed certificate and explicit knowledge cutoff.
8. Leakage tests fail closed.
9. A later-data file cannot be read during model fitting.
10. Results distinguish point error from uncertainty calibration.
