# ElementZero Historical Benchmark Report v1

Generated by `elementzero.reporting.historical` from committed artifacts only. Rebuild
and verify with `python scripts/reproduce_historical_report.py`.

## Contents

| File | What it is |
| --- | --- |
| `ElementZero_Historical_Benchmark_Report_v1.md` | the report itself, all 20 required sections |
| `aggregate_metrics.json` | machine-readable source of every table in the report |
| `model_table.csv` | primary and calibration metrics, one row per epoch and model |
| `distance_table.csv` | metrics per nearest-training L1 distance bucket |
| `benchmark_status.json` | machine-readable status, failures, and next gate |
| `artifact_manifest.json` | every committed input the generator read, with hashes |
| `figures/` | deterministic SVG figures, generated from the committed JSON |
| `SHA256SUMS.txt` | `sha256sum -c` manifest of every file in this directory |

## Reading rules

- Numbers in `ElementZero_Historical_Benchmark_Report_v1.md` are rounded for display. The exact values are in
  `aggregate_metrics.json` and in the CSV files, where floats use the 12-digit
  canonical form from ADR-0002.
- Quantities the preregistration did not declare carry the `POST_HOC` label
  wherever they appear.
- All three epochs and all three models are present, including the poorly behaved
  combinations. Nothing is dropped and no model is labelled best.
- Figures are secondary to the tables and are generated from the committed artifacts
  they declare in `aggregate_metrics.json -> figures`.
